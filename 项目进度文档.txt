一、项目概况
--------------------------------------------------------------
项目名称: 移动端短视频智能剪辑APP
技术栈:
  前端: Flutter 3.8+ / Dart / Provider 状态管理
  后端: Spring Boot 3.2.5 / Java 17 / JPA + Hibernate
  数据库: MySQL 8.0+ (JPA ddl-auto:update 自动建表)
  视频处理: FFmpeg (服务端)
  智能功能: CNN+LSTM 场景识别 / 百度 ASR 语音识别
  
项目路径: F:\26毕设2\移动端短视频智能剪辑app\
前端路径: frontend\
后端路径: backend\

四、已知限制与后续建议
==============================================================

1. 视频导入方式: 目前通过 FilePicker/ImagePicker 选择文件，
   不支持直接拖放到APP界面(Android系统限制)。
   模拟器中需先拖放文件到模拟器窗口，再在APP内通过"相册选择"找到。

2. 后端连接: 前端默认连接 http://10.0.2.2:8080 (模拟器专用)。
   真机测试需修改 constants.dart 中的 baseUrl。

3. FFmpeg: 需要在服务器上安装 FFmpeg 并配置到 PATH。

4. 百度ASR: 字幕功能依赖百度语音识别API，需要有效的 AppID/API Key。

5. 潜在优化方向:
   - 视频缩略图预览 (当前只显示"片段N"文字)
   - 撤销/重做功能
   - 多轨时间线编辑
   - 视频封面设置
   - 分享到社交平台
