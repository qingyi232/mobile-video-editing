==============================================================
   移动端短视频智能剪辑APP - 启动与部署文档
   (Android Studio 方式)
==============================================================

一、环境准备
--------------------------------------------------------------

1. Java JDK 17+
   下载: https://adoptium.net/
   安装后配置 JAVA_HOME 环境变量

2. Android Studio (最新版)
   下载: https://developer.android.com/studio
   安装时勾选:
   - Android SDK
   - Android SDK Platform (API 34)
   - Android Virtual Device (AVD)

3. Flutter SDK (3.8.1+)
   下载: https://docs.flutter.dev/get-started/install/windows
   解压到如 C:\flutter
   添加 C:\flutter\bin 到系统 PATH

4. MySQL 8.0+
   下载: https://dev.mysql.com/downloads/installer/
   安装后创建数据库

5. Maven 3.8+
   下载: https://maven.apache.org/download.cgi
   添加到 PATH

--------------------------------------------------------------
二、后端启动 (Spring Boot)
--------------------------------------------------------------

1. 进入后端目录:
   cd 移动端短视频智能剪辑app\backend

2. 配置数据库:
   编辑 src/main/resources/application.yml 或 application.properties
   修改数据库连接信息:
     spring.datasource.url=jdbc:mysql://localhost:3306/video_edit_db
     spring.datasource.username=root
     spring.datasource.password=你的密码

3. 创建数据库:
   mysql -u root -p
   CREATE DATABASE video_edit_db CHARACTER SET utf8mb4;

4. 启动后端:
   方式A - 命令行:
     mvn spring-boot:run

   方式B - Android Studio / IntelliJ IDEA:
     打开 backend 文件夹
     找到 Application.java 主类
     右键 -> Run

5. 验证后端:
   浏览器访问 http://localhost:8080
   应该看到后端响应

--------------------------------------------------------------
三、前端启动 (Flutter - Android Studio)
--------------------------------------------------------------

1. 用 Android Studio 打开前端项目:
   File -> Open -> 选择 "移动端短视频智能剪辑app\frontend" 文件夹

2. 安装 Flutter 插件:
   File -> Settings -> Plugins
   搜索 "Flutter" 和 "Dart" 插件并安装
   重启 Android Studio

3. 配置 Flutter SDK:
   File -> Settings -> Languages & Frameworks -> Flutter
   设置 Flutter SDK path (如 C:\flutter)

4. 安装依赖:
   打开 Android Studio 底部 Terminal
   执行: flutter pub get

5. 创建/启动模拟器:
   Tools -> Device Manager
   点击 "Create Device"
   选择 Pixel 6 或其他设备
   选择系统镜像 API 34 (Android 14)
   点击 Finish 创建
   点击播放按钮启动模拟器

6. 运行APP:
   等模拟器完全启动后
   点击 Android Studio 顶部绿色 Run 按钮 (▶)
   或在 Terminal 执行: flutter run

7. 后端连接配置:
   前端默认连接 http://10.0.2.2:8080
   (10.0.2.2 是 Android 模拟器访问宿主机的特殊IP)
   如需修改, 编辑:
   frontend/lib/utils/constants.dart
   修改 baseUrl 字段

--------------------------------------------------------------
四、导入视频/音乐到模拟器
--------------------------------------------------------------

方式1: 拖放
   直接将视频/音乐文件拖放到模拟器窗口
   文件会存储到模拟器的 /sdcard/Download/ 目录

方式2: ADB 命令
   adb push 本地文件路径 /sdcard/Download/
   例如: adb push D:\test.mp4 /sdcard/Download/

导入后在APP中操作:
   视频: 编辑器 -> 基础编辑 -> "相册选择" -> 找到文件
   音乐: 音乐库 -> 右上角"导入"按钮 -> 选择音频文件

六、技术栈
--------------------------------------------------------------

前端: Flutter 3.8+ / Dart
后端: Spring Boot 3.2.5 / Java 17
数据库: MySQL 8.0+

--------------------------------------------------------------
七、常见问题
--------------------------------------------------------------

Q: flutter run 报错 "No connected devices"
A: 确保模拟器已启动，或执行 flutter devices 查看设备列表

Q: 连接后端失败 "Connection refused"  
A: 1) 确认后端已启动在 8080 端口
   2) 模拟器中用 10.0.2.2 而非 localhost
   3) 确认防火墙未阻止 8080 端口

Q: 选择文件时文件选择器为空
A: 需要先将文件拖入模拟器或通过 adb push 传入
   文件存储在 /sdcard/Download/ 目录

Q: 编译报错
A: 执行 flutter clean 清理缓存后重新 flutter pub get
