================================================================================
  移动端短视频智能剪辑 APP — 部署与启动说明
================================================================================
【必须】
  - 64 位 Windows，能联网下载安装包。
  - JDK 17（推荐 Eclipse Temurin 或 Oracle JDK 17）。
  - Apache Maven 3.8+（用于编译运行后端；项目未自带 mvnw）。
  - MySQL Server 8.0.x，安装时记住 root 密码。
  - Flutter SDK（stable 稳定版），路径建议全英文，例如：H:\dev\flutter
  - Android Studio（含 Android SDK、可选模拟器）。


--------------------------------------------------------------------------------
一、项目是什么、包含哪些部分
--------------------------------------------------------------------------------

本仓库是一个「前后端分离」的毕设/演示项目，包含三部分：

  1) 后端（backend/）
     Java + Spring Boot 3，提供 REST 接口、JWT 登录、视频处理（依赖 FFmpeg）、
     文件上传与静态资源访问。默认监听端口：8080。

  2) 数据库
     MySQL 8。库名默认：video_edit。表结构由程序首次启动时自动创建/更新（JPA）。

  3) 移动端（frontend/）
     Flutter 项目。在 Android 模拟器里运行时，通过固定地址访问你电脑上的后端。

三者关系（简化）：

  [手机/模拟器上的 Flutter App] --HTTP--> [本机 8080 后端] --JDBC--> [MySQL]

三、重要概念（新手必读，避免踩坑）
--------------------------------------------------------------------------------

  1) 后端地址与手机如何访问电脑
     - 后端跑在本机时，你在浏览器里测试用：http://localhost:8080
     - Android 官方模拟器里，「localhost」指向模拟器自己，不是电脑。
       因此 App 里已配置为：http://10.0.2.2:8080
       10.0.2.2 是模拟器访问「宿主机」的特殊 IP。
     - 若使用真机：手机与电脑需在同一 WiFi；把 App 里 baseUrl 改成你电脑的
       局域网 IP，例如 http://192.168.1.100:8080（下文「真机调试」一节）。

  2) HTTP 与明文流量
     本开发配置使用 HTTP（非 HTTPS）。Android 侧已在清单中允许明文流量，
     以便访问 http://10.0.2.2:8080。若你改为 HTTPS，需同步调整证书与配置。

  3) 项目路径尽量不要用中文或特殊符号
     若整个工程放在中文路径下，Android 构建可能要求额外配置（本仓库已在
     android/gradle.properties 中做了说明性设置）。最稳妥方式：将工程放在
     纯英文路径，例如 D:\projects\video_edit_app。

  4) 没有默认账号
     数据库不会预置「admin/123456」这类账号。首次使用请在 App 内「注册」，
     或自行往数据库插入用户（密码需 BCrypt，不推荐新手操作）。

四、安装与配置逐步说明
--------------------------------------------------------------------------------

【步骤 A — 安装 JDK 17】

  1. 下载并安装 JDK 17。
  2. 配置环境变量（系统属性 → 高级 → 环境变量）：
     - 新建 JAVA_HOME = JDK 安装根目录（例如 C:\Program Files\Eclipse Adoptium\jdk-17.x.x）
     - 编辑 Path，追加：%JAVA_HOME%\bin
  3. 打开「命令提示符」或 PowerShell，执行：
       java -version
     应看到 17 字样。

【步骤 B — 安装 Maven】

  1. 下载 Apache Maven 二进制包，解压到英文路径，例如 C:\tools\apache-maven-3.9.x
  2. 环境变量 Path 中追加：C:\tools\apache-maven-3.9.x\bin
  3. 新开终端执行：
       mvn -v
     应显示 Maven 与 Java 信息。

【步骤 C — 安装 MySQL 8】

  1. 运行 MySQL Installer，选择 Server，安装完成。
  2. 记住 root 密码。若你设置的密码不是 root，请记下，后面要改配置文件。
  3. 确保 MySQL 服务已启动（「服务」里 MySQL80 为正在运行）。
  4. （推荐）用命令行或 MySQL Workbench 执行：

       CREATE DATABASE IF NOT EXISTS video_edit
         CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

     说明：即使不手动建库，部分环境下 Spring 连接串也可能自动建库；手动创建更稳妥。

【步骤 D — 配置后端数据库账号（必须与你的 MySQL 一致）】

  打开文件：
    backend\src\main\resources\application.yml

  找到：

    spring:
      datasource:
        url: jdbc:mysql://localhost:3306/video_edit?...
        username: root
        password: root

  - 若你的 root 密码不是 root，请把 password: 改成你的真实密码。
  - 若 MySQL 端口不是 3306，请改 url 中的端口号。

  保存文件。

【步骤 E — 安装 FFmpeg 并加入 PATH】

  1. 从 FFmpeg 官网下载 Windows 构建版本（带 bin\ffmpeg.exe 的 zip）。
  2. 解压到英文路径，例如 C:\ffmpeg
  3. 将 C:\ffmpeg\bin 加入系统 Path。
  4. 新开终端执行：
       ffmpeg -version
     能输出版本号即可。

  说明：application.yml 中 app.ffmpeg.path 默认为 ffmpeg，即依赖 PATH 能找到命令。

【步骤 F — 安装 Flutter SDK】

  1. 将 Flutter 解压到「纯英文路径」，例如：H:\dev\flutter
  2. 将 H:\dev\flutter\bin 加入用户 Path（环境变量）。
  3. 新开终端执行：
       flutter doctor -v
     按提示安装 Android 许可、接受协议等。

【步骤 G — 安装 Android Studio】

  1. 安装 Android Studio，在 SDK Manager 中安装：
     - Android SDK Platform（与项目 compileSdk 匹配即可，一般较新版本可兼容）
     - Android SDK Build-Tools
     - 至少一个模拟器系统镜像（例如 API 34/35）
  2. 创建一个 Virtual Device（AVD）用于运行 App。

五、启动顺序（每次开发建议按此顺序）
--------------------------------------------------------------------------------

  ① 启动 MySQL 服务（若未开机自启则手动启动）。
  ② 启动后端 Spring Boot。
  ③ 启动 Android 模拟器（或连接真机）。
  ④ 运行 Flutter App。

--------------------------------------------------------------------------------
六、启动后端（详细）
--------------------------------------------------------------------------------

  1. 打开终端，进入后端目录（请把路径改成你本机实际路径）：

       cd /d F:\你的路径\移动端短视频智能剪辑app\backend

  2. 首次建议下载依赖并打包测试：

       mvn -q -DskipTests package

     若报错，根据报错检查：JDK 版本、网络（Maven 中央仓库）、MySQL 是否可连。

  3. 启动服务：

       mvn spring-boot:run

     或先 package 再：

       java -jar target\video-edit-backend-1.0.0.jar

  4. 看到日志中出现 Tomcat started on port(s): 8080 即表示成功。

  5. 浏览器访问（可选）：

       http://localhost:8080

     若返回 404 或空白属正常（未配置首页）；只要端口未被占用且进程不退出即可。

  6. 后端会在运行目录下使用/创建上传目录（相对路径 ./uploads/...），请保证磁盘空间充足。

--------------------------------------------------------------------------------
七、配置并启动 Flutter 前端（Android 模拟器）
--------------------------------------------------------------------------------

  1. 确认 API 地址
     打开：frontend\lib\utils\constants.dart
     默认应为：
       static const String baseUrl = 'http://10.0.2.2:8080';
     模拟器访问本机后端时不要改成 localhost。

  2. 配置 Android 本地属性
     打开：frontend\android\local.properties
     确保包含（路径按你本机修改）：

       sdk.dir=你的AndroidSDK路径
       flutter.sdk=你的FlutterSDK路径

     示例：
       sdk.dir=H:\\Android
       flutter.sdk=H:\\dev\\flutter

  3. 进入前端目录：

       cd /d F:\你的路径\移动端短视频智能剪辑app\frontend

  4. 获取依赖：

       flutter pub get

  5. 查看设备：

       flutter devices

     应能看到你的模拟器，例如 emulator-5554。

  6. 运行：

       flutter run

     或在 Android Studio 中打开 frontend 文件夹，选择设备后点运行。

  7. App 打开后：先点「注册」创建账号，再登录测试。

--------------------------------------------------------------------------------
八、真机调试（可选）
--------------------------------------------------------------------------------

  1. 手机与电脑同一 WiFi。
  2. 查电脑局域网 IP（cmd 中 ipconfig，看无线或有线网卡的 IPv4）。
  3. 修改 frontend\lib\utils\constants.dart：

       static const String baseUrl = 'http://192.168.x.x:8080';

  4. Windows 防火墙若拦截入站，允许 Java 或端口 8080（专用网络）。
  5. 重新运行 App。

九、常见问题排查（遇到问题按顺序查）
--------------------------------------------------------------------------------

  Q1：App 提示「网络错误，请检查后端服务是否启动」
  A1：
      - 确认后端已启动且监听 8080。
      - 模拟器是否使用 10.0.2.2；真机是否已改为电脑局域网 IP。
      - 电脑防火墙是否放行。
      - 若曾只装后端未开 MySQL，后端可能启动失败，请看后端控制台报错。

  Q2：后端启动失败，数据库连接错误
  A2：
      - MySQL 服务是否运行；端口、用户名、密码是否与 application.yml 一致。
      - 是否已创建 video_edit 库（或允许自动创建）。

  Q3：Gradle / Flutter 构建失败，路径乱码或非 ASCII 报错
  A3：
      - 将整个工程移到英文路径；或保留本仓库已提供的 android/gradle.properties 中
        android.overridePathCheck=true 等说明项。
      - Flutter SDK 放在英文路径（如 H:\dev\flutter）。

  Q4：Kotlin 编译跨盘符错误（C: 与 F: 等）
  A4：
      - 本仓库已在 gradle.properties 中设置 kotlin.incremental=false 以缓解；
        或将工程与 Pub 缓存放同一盘符（高级用户可设置 PUB_CACHE 环境变量）。

  Q5：视频处理失败
  A5：
      - ffmpeg 是否在 PATH 中；后端日志中的错误信息。
      - 上传目录是否有写权限。

  Q6：Maven 下载依赖很慢或失败
  A6：
      - 检查网络；可配置国内镜像（settings.xml），属 Maven 通用操作，此处不展开。

十一、停止服务
--------------------------------------------------------------------------------

  - 后端：在运行 mvn 的窗口按 Ctrl+C。
  - MySQL：一般保持服务运行即可；不需要时可停止服务。
  - 模拟器：关闭 AVD 窗口或在 Android Studio 中停止。

--------------------------------------------------------------------------------
十二、安全与生产环境说明（重要）
--------------------------------------------------------------------------------

  本配置用于本地开发与毕设演示：

  - JWT 密钥、数据库密码、明文 HTTP 等均不适合直接上公网生产环境。
  - 上线前应使用 HTTPS、强密码、独立数据库账户、关闭多余端口、定期备份等。
